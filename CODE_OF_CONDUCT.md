# Code of Conduct

We want `dagayn` to be a practical, respectful, and technically honest open-source project.

## Expected behavior

Contributors and community members should:

- be respectful in code review and issue discussion
- assume good intent, but speak plainly about technical risk
- keep disagreements focused on behavior, design, and evidence
- document decisions clearly when changing user-facing behavior
- avoid harassment, insults, intimidation, or pile-ons

## Unacceptable behavior

The following are not acceptable in project spaces:

- personal attacks or repeated hostility
- discriminatory language or exclusionary behavior
- doxxing, threats, or attempts to embarrass others
- knowingly misleading users about the state of the software
- publishing security-sensitive details irresponsibly

## Maintainer responsibilities

Maintainers may edit, remove, or reject content that makes the project less safe or less usable. They may also pause or end discussions that are no longer productive.

## Reporting

For conduct concerns, open a private security-style report if the matter is sensitive, or contact maintainers through the repository channels that are currently listed in `SECURITY.md`.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, release notes, and other project-managed spaces.
